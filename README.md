# Welcome to the CERA Storm Analysis Tutorials

## Overview

This repository is maintained by the LSU CERA-Group, a team of scientists, researchers, and developers dedicated to studying the potential impacts of storm surge and inland flooding caused by landfalling tropical cyclones. We focus on providing accurate and timely information to decision-makers and first responders to support their preparedness efforts and ultimately save lives and properties.

## Objective

Our objective is to simulate and visualize storm surge using advanced computer models like ADCIRC and the cutting-edge CERA visualization technology. Through this tutorial series we are opening our knowledge to the research community for the post-processing and visualization of storm surge data.

## Tutorials

All tutorials require Python 3.15.2 and the shared packages in `requirements.txt` (`python3 -m pip install -r requirements.txt`). Each tutorial folder has its own README with input data and output details.

| # | Tutorial | Description |
|---|---|---|
| 1 | [Adding Map Features with Cartopy](Adding%20Map%20Features%20with%20Cartopy/README.md) | Geospatial data visualization with Cartopy: projections, map features, and station overlays. |
| 2 | [Analyzing NetCDF Files](Analyzing%20NetCDF%20Files/README.md) | Inspect ADCIRC NetCDF files: structure, metadata, dimensions, and data values. |
| 3 | [Creating Map Contours with Matplotlib](Creating%20Map%20Contours%20with%20Matplotlib/README.md) | Create contour maps from ADCIRC NetCDF data with Matplotlib. |
| 4 | [Visualizing a Single NHC Track with Matplotlib](Visualizing%20a%20Single%20NHC%20Track%20with%20Matplotlib/README.md) | Render a single ATCF best-track file as a publication-style map. |
| 5 | [Visualizing Multiple NHC Tracks with Matplotlib](Visualizing%20Multiple%20NHC%20Tracks%20with%20Matplotlib/README.md) | Plot the Atlantic best-track catalog as regional overview maps. |
| 6 | [Calculating River Flow](Calculating%20River%20Flow/README.md) | Fit a stage-discharge curve and fetch historical RiverGages data. |
